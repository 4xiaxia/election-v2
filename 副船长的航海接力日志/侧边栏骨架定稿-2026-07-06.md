# 侧边栏骨架定稿（2026-07-06 三方小圆圆共识）

## 确认对的核心思路
母表（选举详情页）是枢纽，一套菜单 + 权限阉割区分超管/村级，能复用绝不做两套。

## 超级管理侧边栏（4模块，按超管使用频率排序）
```
1. 选举活动管理  ← 置顶（超管每天点）
   - 全部活动（各村母活动列表）
   - 编辑选举活动（母表：11阶段+子公告+材料+候选人+岗位）
2. 选举提案审批
   - 提案列表（各村申请，超管审批/驳回）
3. 岗位管理
   - 全部标准岗位 / 当前在任 / 历史换届名录（→改只读视图）
4. 村居管理
   - 村/社区管理 / 各人员配置（→并入 user-v2）
```

## 村级管理（经办/审核/运营）= 同套菜单权限阉割
- 砍掉村居管理（自己村固定不配人）
- 选举提案审批 → 改"我的选举申请"（提交+查状态）
- 选举活动管理 → 只看自己村
- 岗位管理 → 只保留查标准岗位

## 母表内部（不在侧边栏一级菜单）
候选人提名审核 / 私信通知 / 材料审核 —— 点进选举活动后操作
