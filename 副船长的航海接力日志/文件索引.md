## 当前代码锚点

- `koaLite/api/position-v2.js`：岗位自动生成后端主干。
- `koaLite/api/election-proposal-v2.js`：选举提案提交/审批，使用 `election_proposals` 表，附件自动进归档文件夹。
- `koaLite/api/roster-v2.js`：花名册最小 API，承接岗位详情“在岗”和历史在任名录。
- `koaLite/api/election-v2.js`：母档案增改查、选举方式规则、`content` 的 `templateKey/timeline/stages` 兼容合同。
- `koaLite/api/notice-v2.js`：18 公告模板生成、阶段公告 `stageKey` 查询和公告归档字段。
- `koaLite/scripts/check-position-generate.js`：岗位生成和 `postCategory` 自检。
- `koaLite/scripts/check-election-content-contract.js`：母活动 `content` 兼容合同自检。
- `koaLite/scripts/check-roster-v2.js`：花名册 payload/校验/映射自检。
- `koaLite/scripts/check-router-api-prefix.js`：路由双前缀自检。
- `koaLite/scripts/seed-election-timeline.js`：演示活动 11 阶段母表和 18 公告阶段锚点 seed。
- `koaLite/scripts/seed-subadmin-roster-demo.js`：涧口子管理账号和主任/副主任/委员 active 在岗花名册演示数据 seed。
- `admin/src/views/positions/index.vue`：岗位页已接“在岗花名册”弹窗，读取/新增/停用 `roster-v2`。
- `admin/src/views/election-proposals/index.vue`：提案页附件已从 URL 输入改为上传，提交后刷新不丢。
- `admin/src/api/api.ts`：roster API 包装和 `submitMaterial` 兼容导出。
