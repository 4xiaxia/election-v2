## 1. 树根主线

```mermaid
flowchart LR
    V[villages<br/>122归属地] --> E[elections<br/>换届母档案]
    E --> T[content.timeline<br/>当前模板stages]
    E --> P[positions<br/>主任/副主任/委员]
    P --> C[candidates<br/>候选人]
```

## 4. 数据库立足点核对

```mermaid
flowchart LR
    OK[已对上<br/>villages/elections/positions/materials/notices/candidates/notifications/election_voters]
    HALF[半对上<br/>timeline JSON合同/notice stageKey筛选/提案scope]
```

## 4.1 角色视角盘点

```mermaid
flowchart LR
    Sub[子管理<br/>当前村/社区] --> Same[同一套母活动视角]
    Super[超级管理<br/>全部归属地列表] --> Down[选择村/社区下钻]
    Down --> Same
    Operator[运营<br/>公告/通知/结果/归档] --> Same
    Reviewer[审核<br/>材料/候选资格] --> Mat[materials/candidates]

    EID --> Gap[下一刀缺口<br/>stageKey筛选 + templateKey合同]
```

## 5. 母版主体表到侧边栏

## 6. 子管理 UI 当前回路

```mermaid
flowchart LR
    Login[登录绑定角色+归属地] --> Dash[子管理仪表盘]
    Dash --> Guide[系统施工导览<br/>漏斗/侧边栏/字段]
    Dash --> Calendar[日历日程<br/>elections.content.timeline]
    Dash --> Activity[本村/社区活动列表<br/>GET election-v2/list]
    Activity --> Mother[母版详情 /election/:id<br/>时间轴表]
    Mother --> Archive[阶段归档材料<br/>materials.scope=archive]
    Mother --> Notices[公告编辑<br/>notice-v2]
    Dash --> Positions[岗位管理<br/>positions.election_id]
    Positions --> JobModal[岗位详情弹窗<br/>electionId+positionId]
    JobModal --> Roster[在岗: roster-v2<br/>已落最小表/API]
    JobModal --> Materials[报名: materials.scope=candidate]
    JobModal --> Candidates[候选人管理<br/>candidate-v2]
    JobModal --> Result[结果回填<br/>candidate-v2/result]
```

## 7. 硬边界

```text
主任/副主任/委员 = 一期竞选主线
代表/小组长/监会/移交 = 归档或二期
candidate材料通过审核才进候选人
archive材料只归档不进候选人
users不是选民登记，election_voters才是某届选民
花名册进一期，但只做 roster 最小表；不扩复杂干部履历
```
