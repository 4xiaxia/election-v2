# 系统总收口（一句话看懂整套系统）

夏夏 2026-07-12 收口："其他侧边栏菜单，数据又是映射的。" **母版是唯一的源，其他菜单全是它的投影，没有一个自产数据。**

## 映射全景
```
        ┌───────────────────────────────────┐
        │  母版（一届填空套题·唯一数据源）      │
        │  阶段名 · 时间轴 · 岗位 · 固定模板    │
        └───────────────────────────────────┘
                     │ 全是读它、映射出去
   ┌──────┬──────┬──┼──┬──────┬──────┬──────┐
  首页   提案   岗位  材料  候选人  公告   归档
```

| 侧边栏菜单 | 读母版什么 | 映射成什么 |
|---|---|---|
| 首页仪表盘 | 全部 | 速览+快捷入口投影 |
| 提案审批 | 阶段产出 | 弹窗看，不做重页 |
| 岗位管理 | type+岗位规则 | 主任/副主任/委员坑位 |
| 材料提交 | 阶段+固定模板 | 引用模板地址，不重存 |
| 候选人管理 | 阶段时间 | 算提名/入围/竞选3阶段 |
| 公告通知 | 阶段名+时间 | 各阶段子公告，引用字段 |
| 历史归档 | 阶段名 | 文件夹名=阶段名，只读投影 |

## 真正要动脑造的只有三块（"傻兮兮"的终极形态）
1. **母版**（源：填空套题+四件事+时间轴）
2. **候选人管理**（唯一有真审批逻辑：三阶段漏斗+淘汰冻结+详情弹窗）
3. **仪表盘**（投影布局）
其余全是"读母版→套映射→显示"，查表不算、照抄不造。

## 施工顺序的根据
**母版是根，必须最先扎稳。** 母版清干净(清多余岗位/砍地图/换皮)、填空口留对，其他6块菜单就是"换皮不动骨"照着映射长出来。根正了其余全好办。

**How to apply**：任何侧边栏菜单开工前，先问"它读母版的什么、映射成什么"，别在映射模块里写独立逻辑/造第二套数据。先做母版再做其余。真正的脑力只花在母版+候选人+仪表盘三块。
