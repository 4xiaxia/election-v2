# 岗位规则铁律（法条级）

夏夏 2026-07-10 定稿。**代码里若出现党组织岗位、村监会/居监会、代表、小组长、楼栋长等，是历史遗留错误，必须清理，不是需求。** 一期竞选岗位严格只有：主任、副主任、委员。

## 一、岗位层级（村委、居委会内部完全一样）
1. **主任**：一把手，全面总负责，第一责任人。
2. **副主任**：二把手，主任助手，主任不在时代管全盘，分管几块重点工作。
3. **委员**：普通班子成员，只负责某一条线业务（民政、卫健、调解、治安等）。

层级：主任 > 副主任 > 委员。**三个职位是三张独立选票职位，分开竞选、分开计票，不能混。**

## 二、村委会 vs 居委会 核心区别（写进系统配置）

### 1) 班子总人数（硬性法律规定，单数）
- **村委会（行政村）**：主任+副主任+委员合计 **3~7 人**
  - 小村：3 人（主任1 + 委员2，可不设副主任）
  - 大村：5 / 7 人，可增设副主任 1~2 名
- **居委会（城市社区）**：合计 **5~9 人**，一般必须 5 人起（很少无副主任）

### 2) 选举方式（系统写死，不能乱选）
- **村委会（村）**：只能一种——全体年满18周岁村民直接投票（全民直选）。**禁止**户代表、居民代表模式。
- **居委会（社区）**：三选一（后台单选框）——①全体居民直选 ②户代表选举（城市最常用）③居民代表投票选举

### 3) 候选人推荐方式（村居完全一致，仅主任/副主任/委员开放）
三种提名：①本人自荐 ②10名以上村（居）民联名推荐 ③党组织推荐
**重点：只有主任/副主任/委员开放自荐；其他岗位一律关闭自荐入口。**

### 4) 选票职位下拉（两套字典完全相同，只控人数上限）
职位下拉**固定只有三项**：主任、副主任、委员。

## 三、最容易踩坑的 3 条边界（代码判断逻辑）
1. **副主任是独立竞选岗位，不是委员提拔**：单独报名、单独投票，不能先选委员再提拔。
2. **委员 ≠ 治保主任/妇联主席**：妇联、综治、民政只是当选委员后的内部分工，竞选页面没有这些岗位，当选后再分配。
3. **小村委可不设副主任**（3人班子=主任+2委员）；居委会最低5人，很少无副主任。

## 四、法律依据
- **村委会（农村）**：《村民委员会组织法》——主任/副主任/委员由全体登记选民直接投票产生。严禁户代表、居民代表间接模式。（集体资产多，须保障每位村民投票权，杜绝民意被截留）
- **居委会（城市社区）**：《居民委员会组织法》——三种方式任选其一（直选/户代表/居民代表）。（人口流动大、居住分散，允许简化投票人员范围）

## 五、硬性判断语句（代码）
```
如果 村居类型 = 行政村：
    锁定选举方式 = 全体村民直选
    隐藏「户代表」「居民代表」两个选项
如果 村居类型 = 城市社区：
    开放三个选项自由选择
```

## 五之二、数据固定性质高 = 省力地基（夏夏 2026-07-12 点透）
整套系统能被做"傻兮兮"、能省力，根本原因是**数据固定性质极高——三层全是写死的枚举，不是自由输入**：
| 层 | 固定成啥 | 由谁决定 |
|---|---|---|
| ① 归属地类型 | 村委会 / 居委会（122村居各自定死） | villages.type，已灌真数据 |
| ② 选举方式 | 村委会→只能直选(锁死无选择)；居委会→三选一 | 法律强制，读①自动定 |
| ③ 岗位 | 永远只有主任/副主任/委员（两套字典相同，仅人数上限不同） | 法条铁律，写死 |

**两条写死的法律链**：村委会↔直选↔主任/副主任/委员；居委会↔三选一↔主任/副主任/委员。系统只做"读type→套对应链→显示固定项"，不做任何自由裁量。
**关键落地铁律**：**这些全是固定下拉/单选，绝不能做成自由输入框。** 村→选举方式栏灰掉锁死；社区→给三个单选框；岗位下拉永远就那三项。没有自由填的口子=错误无处发生(不会"村委会却选了户代表"这种违法操作)。数据越固定，逻辑越是"读字段→查固定对照表→显示"，查表不算，不动脑。这是"傻兮兮省力"的地基。

## 六、岗位管理 UI（UI优化稿捞回·小圆圆曾漏）
岗位管理含两个全屏弹层，均绑 `positions.election_id`（某一届的，不是全局通用）：
- **岗位说明**：富文本编辑岗位职责/任职要求。字段 `positions.name/quota/duty/material_requirements/enabled`，保存 `POST /position-v2/update`。
- **表格下载**：挂材料模板下载链接，`positions.material_requirements[].url`（结构 name/type/url/required）。给前端下载，不能和 `materials.scope=archive` 存档材料混。
