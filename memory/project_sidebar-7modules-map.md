# 侧边栏7模块骨架图

夏夏 2026-07-11 给的完整侧边栏映射。**所有模块同构**：一级功能 → 二级历届列表 → 三级点某届下钻明细。这是"历届是刚需"漏斗铁律的具象清单。

| 一级模块 | 三级下钻 | 夏夏批注（难度/决策） |
|---|---|---|
| 🏠 首页工作台 | 无下级 | 仪表盘快捷入口 |
| 📄 提案审批 | 提案详情 | **不做重点，详情走弹窗不跳页**（能弹窗就不造页面） |
| 📋 选举活动管理 | 母活动小看板 | **重点是母版** |
| 👥 岗位管理 | 该届岗位增删改查明细 | 没难度 |
| 📝 材料提交管理 | 该届材料审核明细 | **特殊要注意** |
| 🙋 候选人管理 | 该届候选人审批管理 | **特殊**：审核分3阶段；审批已确认合并进此模块（见候选人审批漏斗表记忆） |
| 📢 公告通知 | 该届阶段公告编辑发布 | 与母版阶段**一一映射、不改逻辑**；母版快捷编辑顺手引用字段，主为**存档留痕** |
| 🗄️ 历史归档 | 该届文件夹目录树 | 同公告：与母版阶段一一映射，母版编辑引用，主为**存档** |

## 两个"骨"
1. **提案审批降级**：夏夏明说"不做重点、弹窗解决省得跳页"。跟管理员配置、通知同路子——**能弹窗就不造独立页面**。
2. **公告 & 归档 = 母版的投影兼存档**：这俩不自产内容，是母版各阶段的镜像。母版一处编辑，两边字段跟着引用；存下来是为留痕。又一次"改母活动一处、处处跟着变"骨牌律的落地。

**How to apply**：做任何模块前先看这张图定位它在漏斗里的层级和难度。公告/归档别写独立编辑逻辑，复用母版阶段字段。提案审批别做重页面，弹窗解决。
