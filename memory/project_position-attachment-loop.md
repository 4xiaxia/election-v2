# 本期岗位弹窗与附件闭环

夏夏 2026-07-11 讲清（原图：屏幕截图 2026-07-10 072049.png）。

## 本期岗位页结构（原设计）
- 顶部「参选人支持形式(可多选)」：个人自荐 / 群众联名推荐
- 「关联选举活动」下拉：选哪一届
- 每个岗位一行（居委会主任/副主任/委员），各带两按钮：**岗位说明** + **表格下载**

## 点击弹窗（详情）
- 点岗位进去是**弹窗**，弹窗=详情。
- 弹窗里**管理员可设置这些附件的下载地址**——而附件**其实是从材料管理里捞的**，不另存一份，引用材料管理的文件。

## 核心骨：附件从材料管理捞、不重存
又一次"一份数据一个源"的映射——附件真身在材料管理，本期岗位只引用地址。同归档"投影母版不自产"、公告"引用母版字段"一根骨。

## 三块闭环
```
材料管理(存空白模板 + 收回传件)
   ↑捞下载地址            ↑回传盖章件
本期岗位(表格下载弹窗) → 用户下载→打印盖章填完 → 候选人详情(预览这份附件)
```
用户流程：表格下载→打印盖章→填完回传→回传件即候选人详情里要预览的附件（复印件）。

**How to apply**：做本期岗位页时，附件下载地址引用材料管理的文件，别重存一份。点岗位走弹窗详情。这块与候选人详情弹窗的附件预览、材料管理是同一份数据的三个入口。
