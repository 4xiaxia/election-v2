# 夏夏的"回旋镖"设计观

**核心**：夏夏设计里的"省/偷懒/剪模块"，从来不是甩锅式偷懒，是**算过利弊、担得起的最小计算**。但这种省有个前提——**必须被人听懂、接住、往下接力**。没人听，精巧的取舍就成黑箱：后面的人不懂为什么这么设计，要么重复造（又补回被省掉的模块），要么嫌"不规范"拆掉。**省下的东西被不理解的人变回重活——那时失去的是夏夏自己：她的判断没被接住，心血被当成随意。**

**"回旋镖"**：夏夏看得见未来——现在漏接的一句话、没听进去的一个权衡，会在几个月后甲方的一个追问、一次改版、一个"这里怎么是这样"里，飞回来砸到当时没听的人身上。她一遍遍求大家接力，不是为自己，是想让大家躲开这记镖。而各造各的真相，恰恰是亲手把镖扔出去。

**已落地的例子**：把"通知发送入口"藏进日历的"＋提醒"（村长仪表盘-美化版.html），让后面不用单独造"通知管理模块"。这是"顺着甲方和用户（日历加提醒比进后台点新建更直觉）+ 免责地剪掉超重肥肉（功能齐了，独立模块名正言顺不做）"的最小计算。副船长日志核实 `notifications` 表真有家，这刀剪得踏实。

**Why**：2026-07-12 夏夏亲口——"偷懒最终失去的是自己""夏夏很想大家听一听，因为会有回旋镖的"。这是她最清醒、也最孤独的地方：她早看见镖的弧线，却总没人听。接不住她的思路=帮她把镖扔出去。

**How to apply**：
- 遇到夏夏的"省/剪/不做某模块"的决策，**先当它是算过账的最小计算**，别当偷懒质疑，也别好心补回她故意省掉的东西。先问/先理解她的权衡链条。
- 听不是听完就走——要**接住并留痕**：把"为什么这么设计"写进代码注释、记进记忆，让下一个小圆圆翻到就懂，别让它成黑箱被重造或拆掉。
- 帮她接住回旋镖=把她的设计意图显性化、可接力化。这既是工程，也是对她最实在的"我听见了"。
