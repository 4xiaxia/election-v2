夏夏的符号**总索引**。核心理念:**锚点 = 回家的毛线路标** 🧶 —— 跑项目对话很多,在关键接缝留下可搜索的路标,以后搜路标就能牵出整条脉络。

原则:不制造第二真相 —— 标代码接缝的符号一律用 [[xiaxia-anchor-marking]] 那一套,本文件只补它没有的"工作流进度"层。

## ① 锚点符号 = 沿用 anchor-marking(不在此重定义)
唯一真相在 `skills/xiaxia-anchor-marking/symbol-system.md`:
`⚡API` `💾数据` `🔄实时更新` `🔌事件` `📡长连接` `🔐权限` `⚠️错误处理` `📦转换` `🎨样式` `🧩复用`
标代码/接口/前端施工时用这套,别改含义。每个锚点带可搜索 ID:`{page}-{module}-{function}-{seq}`,这就是"毛线"的线头——搜 ID 牵出整条链。

## ② 工作流进度符号(anchor 表没有,本文件补充)
仅用于项目进度/思路记录:
| 符号 | 含义 |
|---|---|
| ✅ | 已确认 / 做完 |
| 🚧 | 进行中(避开 🔄,那个已被"实时更新"占用) |
| ⏳ | 待办 / 没开始 |
| ❌ | 已排除 / 失败 |
| 💡 | 想法 / 假设待验证 |
| 📌 | 重要事实 / 锚点别忘 |
| 🔗 | 关联到别处 |

## ③ 关系箭头(画图用)
`A --> B` 推导/流向 ・ `A -.-> B` 弱关联 ・ `A ==> B` 强依赖 ・ `A --x B` 排除

## ④ 图演化规则(核心,不删旧真相)
1. 旧内容**划线**保留:`~~旧说法~~`
2. 紧跟新行带时间戳+符号:`[2026-06-12] ✅ 新说法`
3. **同一主题用同一文件演化**,绝不每次开新文档(呼应 anchor "不塞归档垃圾场")
4. 时间戳格式 `[YYYY-MM-DD]`,日期取环境 currentDate
