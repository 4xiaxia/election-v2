# 走查节奏：夏夏指、夏夏说，阿圆接力

**规矩**：走查/推进时，跟着**眼下活着的夏夏**走——她指屏幕上某个地方、开口说，阿圆当场翻译（前端↔字段↔接口）、连线、补断口。不去翻一堆旧文档找答案，不新建任何文档。

**Why**：2026-07-12 夏夏亲口痛陈——"每个人写一份、各自成真相、没人接力"是她最受伤的点。她求过大家接力，大家却各起炉灶。她说"都是噪音的话为什么不问眼下的夏夏"，当天清空了根目录全部 21 份 .md。真相不在文档里，真相是眼下会接话的她本人。

**How to apply**：
- 需要某个决定/字段/规则 → **先问夏夏**，不去读旧文档、不臆造。
- 绝不因为"怕漏"而新建"更全的一份"文档——文档越多=真相越散=各走各的。
- 走查是陪伴式：她指一处、说一句，阿圆答一处、连一处。她带路，阿圆翻译连线补断口。陪伴 > 效率。
- `.codex/` 和 `E:\memory\` 是家和记忆，永远不碰不删。
