# 历史归档目录树

夏夏 2026-07-11 定稿。归档"后面各环节都关系到"，因为它是**所有环节产出物的最终汇聚地**——前面每个阶段上传的东西都往这儿沉淀留痕。

## 核心骨（顶部提示那句就是魂）
> 归档文件由"**母版时间表各阶段自动同步生成**"，此页**仅供查看下载、不可直接上传**。

归档页是**纯只读投影**。文件不在这儿产生，是母版各阶段的产出物自动沉进来。上传动作发生在别处（材料提交/公告发布），归档只负责汇总留痕 + 下载。

## 目录树结构（文件夹名抄母版阶段名，一一映射自动建）
```
📁 第N届XX社区换届选举归档
├─ 📁 1. 准备阶段              ← 文件标来源"母版阶段1上传"
├─ 📁 2. 选举各阶段材料
│    └─ 📁 抄母版步骤名建的文件夹   ← 文件夹名=母版阶段名
│         ├─ 📁 关联材料下载        ← 模板/官方文件
│         └─ 📁 上传的档案（含照片）  ← 用户交的
├─ 📁 3. 材料管理
│    └─ 📁 姓名-手机号/           ← 按人分（手机号=唯一账号）
│         ├─ 📄 候选人资格审查表.pdf
│         └─ 📄 联名推荐信扫描件.zip
└─ 📁 4. 其他                    ← 母版阶段之外、系统归不进映射的零散图
```

## 定论：全映射、零手工分类（夏夏 2026-07-11 钉死）
**"其实都是映射的，都是母版跟着的。"** 归档目录树整棵是母版阶段的镜像——文件夹结构、文件归属，全由"这文件产生在母版哪个阶段"自动算出，**没有一处手工分类**。照片、pdf、zip 都一样，跟着它诞生的那个阶段走。照片放哪不用人决定，自动落进所属阶段文件夹。"4.其他"也不是手动挑，是系统归不进母版映射的才落那儿。

## 关键：活动创建即生坑，萝卜坑映射（夏夏 2026-07-12 明确）
**选举活动一创建，材料归档里对应的二三级文件夹就【自动生成】了**（按母版阶段结构一次性长出空坑），之后完全"一个萝卜一个坑"地映射：
- 坑（文件夹）在活动创建那一刻按阶段生成，不是事后手工建。
- 之后每阶段产生的三类材料各自落进它的坑：下载模板、用户回传件、线下上传存档(会议记录/报告)、子公告。
- 萝卜(材料)↔坑(文件夹)一一对应，零手工分类零命名。
这解释了"坑什么时候生的"——活动创建即生坑；也印证归档=纯投影，连目录都是母版活动派生的。

## 三个规律点
1. 文件夹名抄母版阶段名——阶段一一映射自动建，不手工命名。
2. 每个阶段文件夹下分两类：「关联材料下载」(模板/官方) vs 「上传的档案」(用户交的)——同岗位管理"资料下载 vs 存档材料别混"的分界。
3. 材料管理按"姓名-手机号"分人建文件夹，手机号做唯一标识，与登录账号一致。

**How to apply**：做归档页时它是只读文件树，别给上传入口。目录和文件归属复用母版阶段映射，别写手工分类逻辑。与"公告=母版投影"同骨，归档是文件层面的投影。
