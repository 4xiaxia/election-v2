# 大母版的本质（这块地的最高纲领）

夏夏 2026-07-12 点透。**大母版 = 一届选举 = 活动总列表里的一行 = 一套题。** 本质是一张**分阶段的填空题卷**。

## 母版每个阶段 = 干这几件事（材料分三股流向·夏夏 2026-07-12 明确）
```
① 填空套题（题干固定，只挖几个空让人填）
      ↓ 时间轴一填，驱动全系统
② 材料·三种流向（别再笼统叫"材料"，流向不同）：
   (a) 下载模板类：后台上传空白模板(各类申请表/自荐表) → 供小程序/C端用户【下载】
       → 用户填完盖章 → 自荐时【上传】回来（=候选人详情要预览的附件）
   (b) 上传存档类：管理员把线下办的东西上传归档(本阶段会议记录①②③④/
       选举结果报告/各种报告表；官方打★的送镇民政那些)——留痕
   (c) 用户回传件：即(a)里用户填完传回的，落候选人材料
③ 发这个阶段的子公告（N号公告，与阶段一一映射）
```
全挂在"阶段"上，阶段全来自母版时间轴。一个阶段推进，它的公告、归档坑、下载模板同时就位。这是母版是地基、"出口大户"的原因。
**材料定义要在页面/字段上写明白**：下载模板(后台上传供下载) vs 上传存档(线下资料留痕) vs 用户回传(自荐上传)——三者流向不同，别混成一个"材料"。

## 填空题：哪是固定题干、哪是该挖的空
- **固定题干（不动，复用）**：阶段步骤、选举形式4套(村委1种直选/居委3种)、岗位就主任/副主任/委员、每阶段用的下载文件模板。
- **要填的空（每届变的，抠窟窿留白）**：时间(各阶段起止)、主题(第X届/哪个村居)、岗位要求变动(名额/班子人数)、少量小细节。
- 填进去的空会流向全系统：时间→日历红条、主题→公告抬头、岗位→报名坑位、阶段名→归档文件夹名。填一次，处处结果。

## 母版是"预设可编辑"，不是必填死表（夏夏 2026-07-12·鸡贼小技巧🤫）
母版不是焊死的必填流程，是**预填好一整套官方标准答案、但可编辑**的填空卷：
- **默认全给**：官方全套阶段都预填好（含"建章立制/工作移交"这类收尾），省各村从零填。
- **都不必填**：各村按自身情况酌情增/删/改——用不上的删、有特殊的加。
- **核心锁、细枝弹（鸡贼骨）**：
  - **锁死不动**（关联别的表、是主数据链关节）：提名(→候选人表)、选民登记(→选民表)、资格审查、投票/选举日、发公告节点。这些一定有，动了别的表就断链。给锁标记+提示"删了会断链"，但核心项直接锁住不让改坏。
  - **留弹性**（细枝末节，预设但可删可编辑）：建章立制、工作移交、具体天数、措辞。
- **甲方观感 vs 真相**：甲方看着是"贴心预填一整套"，实则改坏不了的关节被焊死，只放开改了也不伤筋动骨的地方——既周到又防呆。同"界面给甲方看人话、注释偷着乐"一个路数。
- **前端落点**：阶段行可增/删/改（非静态写死）；字段有默认值预填但核心项不放开、非核心不校验必填；核心关联阶段给锁标记。
- **化解矛盾**：接力锚点"不做工作移交" vs 官方"有工作移交"→ 不二选一，"预设给你、你自己定要不要"，既简化又不丢官方完整。

## 下载模板=甲方给的固定文件，不现造
甲方已给固定文件模板，在 `E:\w\0\election-v2\其他附件材料\`（25.初步候选人自荐表、26.提名表、28.资格审查表、6.选委会提名表等 xlsx/docx/jpg）。这些是现成固定模板挂上去给下载，不是现造。接"本期岗位表格下载从材料管理捞"闭环——**固定模板存材料管理，各阶段/岗位引用其下载地址，不重存。**

## 现存母版页要清的脏（选举系统_填空模板(1).html 是最旧一版）
- **多余岗位（印错的题干，删）**：党组织(书记/支委)、村务/居务监督委员会、村民/居民小组长、楼栋长、镇聘/社工hiredJobs——违反一期岗位铁律(只有主任/副主任/委员)。
- **高德地图(mapPanel/simulateMapLocate，废件，删)**：归属地改成固定下拉(乡镇→村居，用已灌的122条真数据)。
- **旧皮**：紫红渐变header+PingFang/雅黑字体→换美化版(Noto Serif SC+红#B22222/金#C8A45C)。
- 保留留好的"空"：时间、主题、岗位名额那几个填空口。

**How to apply**：做母版/公告/归档/材料任何一块，都从这张纲领出发——母版是分阶段填空卷，每阶段四件事，题干固定只填变量，模板引用材料管理不重存。清理旧母版页时分清"印错的题干(删)"和"该留的空"。
